# Smart Parking Prediction and Recommendation System

## Project Overview
This project uses Machine Learning to predict parking occupancy using historical parking data and recommend parking locations based on estimated available spaces.

## Technologies Used
- Python
- Pandas
- NumPy
- Matplotlib
- Scikit-learn
- Google Colab

## Dataset
Birmingham Parking Dataset.

## Model Evaluation
- MAE: 23.73 spaces
- RMSE: 56.23 spaces
- R² Score: 0.9941

## Project Features
- Data preprocessing
- Time-based feature engineering
- Parking occupancy prediction
- Estimated free-space calculation
- Parking location recommendation
